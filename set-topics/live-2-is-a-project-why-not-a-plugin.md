The main reason for **not** switching ninja to plugin it FAB consistency: live has been set up as a "project" back in 2020". This is a hardwired setting on the marketplace / FAB: you can not change it once set. In order to switch ninja to a "plugin" - **we have to set up a new release**. A new item on fab. A new product, in terms of visibility and listings. Considering the tens of thousands of links pointing to the existing product: this would be a MAJOR source of confusion. Apart from this, we would loose our ratings, and our established position in the FAB page-rank library.
So, from a marketing / visibility / communication point of view, this would be a real disaster.
