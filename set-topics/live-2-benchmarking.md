Ninja defaults to 60 FPS
In order to unlock higher FPS ranges - and see how ninja performs on a given hardware, we need to use the benchmarking tools

1. in case you are in Unreal Editor: start play / in the playable demo, play automatically starts
2. press the little B user interface button at the screen bottom
3. press MaxFPS button
4. watch the FPS counter in the top-left corner of the screen
