To access the version number of your local ninja project, go to the top menu bar in the editor and look up these options:
`Edit /Project Settings /Project /Description /About /Project Version`

Ninja version number is constructed from four digits, separated by dots. For example: 2.0.1.56
The 1st digit is the "major version number", the 2nd and 3rd digits are "sub-versions" and the 4th digit is a reference to the lowest supported Unreal Engine version.

Learn more about the (LIVE-1 to LIVE-2) transition and how to access various ninja versions on FAB, by reading [Manual Chapter 15](https://majorsmash.github.io/fnl-docs-v2/manual/ninjalive2-manual/#15-live-1-vs-live-2)
See this [screenshot](https://drive.google.com/file/d/1WBmawj1gflfCkUDt-kwdHgFz6G5iFgtk/view?usp=sharing), showing how ninja version could be accessed in Unreal Editor.
